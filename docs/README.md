# 文档索引

## 这里放什么，不放什么

`docs/` 只放**给人看的说明**。三类东西不属于这里：

| 不放在 docs | 实际位置 | 原因 |
|---|---|---|
| 给模型看的技能指令 | [backend/skills/](../backend/skills/README.md) | 每次 AI 调用前注入提示词，是代码资产不是文档 |
| 脚本生成的评测报告 | 跑脚本时自动写入 `docs/`（已 gitignore） | 每次评测数字都变，入库只会制造过期数据 |
| 已完成的决策记录 | 删掉 | 结论已落在代码注释里，留着会与实现脱节 |

## 活文档（改代码必须同步）

| 文档 | 内容 | 何时必须改 |
|---|---|---|
| [口径说明.md](口径说明.md) | 16 个术数各自的流派选择、算法步骤、常见差异、不做什么 | 改任何引擎的算法或流派时 |
| [架构与验收.md](架构与验收.md) | 分层边界、守卫规则、例外与验收分层 | 新增层 / 改依赖方向时 |
| [数据库.md](数据库.md) | 表清单、单表外壳的取舍、迁移规范、本地起库 | 加表 / 加迁移时 |

> `口径说明.md` 被后端源码注释引用 8 处，是本项目最需要保持同步的文档。

## 运行时数据

| 目录 | 内容 | 谁在读 |
|---|---|---|
| [知识源/](知识源/) | 公版古籍整理片段（18 个 md，按典籍/域分目录） | `python -m app.domains.knowledge.ingest` 灌库；`infra/Dockerfile.backend` 会 `COPY` 进镜像 |

**入库后才会被引用**。新增片段后必须跑一次 ingest，否则报告检索不到。
格式与审核流程见 [backend/skills/README.md](../backend/skills/README.md) 第 8 节。

## 脚本生成（不入库）

跑下面任一脚本会在 `docs/` 下重新生成对应报告，已在 `.gitignore` 里：

| 文档 | 生成命令 | 内容 |
|---|---|---|
| `模型评测.md` | `python -m scripts.eval_reports` / `bench_eval` | 报告管线指标 + 题库准确率 |
| `题库复盘.md` | `python -m scripts.bench_stats` | 每道题「错/答」、未作答、题库缺口 |
| `蒸馏记录.md` | `python -m scripts.distill_round` | 每轮 train/test/无技能基线 delta |

## 约定

- 术数清单以 `GET /api/v1/meta/domains` 为唯一事实来源；
- 前端入口清单以 `frontend/src/config/domains.ts` 为唯一事实来源；
- 口径类结论以 `口径说明.md` 为准；
- 新增术数时补：口径章节、基准说明、知识源目录、`backend/skills/<domain>/SKILL.md`、`config/domains.ts` 一条。
