# 文档索引

## 怎么读这份索引

文档分五类，**维护方式不同**。改代码前先看「活文档」，别把生成物当规范，也别去改归档。

| 类型 | 含义 | 维护方式 |
|---|---|---|
| **活文档** | 描述当前实现，改代码必须同步 | 人工维护，PR 时一起改 |
| **运行时数据** | 会被程序读取/灌库 | 只增不改格式；灌库走 `ingest` |
| **生成物** | 脚本覆盖写入 | **禁止手改**，改脚本后重跑 |
| **专项说明** | 单个子系统的深入说明 | 该子系统改动时同步 |
| **历史归档** | 当时的决策记录，不再更新 | 只读；结论可能已被实现演进取代 |

## 约定

- 术数清单以 `GET /api/v1/meta/domains` 为唯一事实来源，文档与前端都不另立一份；
- 前端入口清单以 `frontend/src/config/domains.ts` 为唯一事实来源；
- 口径类结论以 `口径说明.md` 为准，评测数字以 `模型评测.md` 为准；
- 新增术数时，至少补：口径章节、基准说明、知识源目录、SKILL.md、`config/domains.ts` 一条。
