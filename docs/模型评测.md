# 模型评测

评测分两条线，指标不同，**不要混着看**：

| 线 | 评测什么 | 生成脚本 | 关键指标 |
|---|---|---|---|
| 报告管线 | 同一批基准命例 → 生成完整报告，走校验链 | `python -m scripts.eval_reports` | schema 通过率、引用合法率、降级率、P50/P95 |
| 题库 | 真实考题（MingLi-Bench）四选一，先算盘再作答 | `python -m scripts.bench_eval` | 准确率、知识库命中、未作答、按类目拆分 |

两条线的共同前提：

- 报告线测「**解释是否合规**」，题线测「**判断是否接近人类**」；
- 题线必须先把盘算好（`scripts/bench/charts.py`），否则测的是排盘能力；
- 题线的训练/留出按**命例**切分，避免同一张盘同时出现在 train 与 test。

逐题复盘与蒸馏记录见 [题库复盘.md](题库复盘.md) 与 [蒸馏记录.md](蒸馏记录.md)。

> 本文件的下半部分由两个脚本**分别覆盖**各自的章节，不要手工编辑对应区块。
