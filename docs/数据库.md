# 数据库

MySQL 8，`utf8mb4` / `utf8mb4_0900_ai_ci`，中文全文检索依赖 `ngram_token_size=2`。

> 口径类结论见 [口径说明.md](口径说明.md)；分层边界见 [架构与验收.md](架构与验收.md)。

## 1. 表清单

### 1.1 账号与安全

| 表 | 作用 | 关键约束 |
| --- | --- | --- |
| `users` | 账号主体 | `email` 唯一；`token_version` 用于「改密即全端下线」 |
| `user_consents` | 合规同意记录 | `(user_id, doc_type, doc_version)`；面相/手相另记 `face_biometric` |
| `refresh_tokens` | refresh 轮换链 | 只存 `jti` 与哈希；用过即废，重放视为被盗 |
| `password_reset_tokens` | 找回密码 | 只存 `sha256`，TTL 30 分钟，同账号最多 3 枚 |
| `audit_logs` | 敏感操作审计 | 只记动作与目标，不记凭据 |

### 1.2 命盘与解读

| 表 | 作用 | 关键约束 |
| --- | --- | --- |
| `chart_records` | **所有术数共用**的命盘外壳 | `domain` + `input_json` + `chart_json` + `convention_json` + `algorithm_version` + `snapshot_hash` |
| `chart_notes` | 命盘笔记 | 归属经 `chart_records.owner_user_id` 传递校验 |
| `share_links` | 分享链接 | 只存 token 的 SHA-256，明文仅创建时返回一次 |
| `ai_reports` | AI 报告 | 快照哈希 + 口径 + 技能版本一起存档；`status` 区分 `complete` / `degraded` |
| `report_followups` | 报告追问 | 独立表而非塞进 `report_json`：追问有轮次上限与自己的校验结果 |
| `llm_calls` | 模型调用记账 | 只记 provider/model/延迟/token/成本/错误码，**不记提示词与用户原文** |

### 1.3 图片（面相 / 手相）

| 表 | 作用 | 关键约束 |
| --- | --- | --- |
| `chart_media` | 上传图片的元信息 | 二进制落文件系统，库里只存 `sha256` + `storage_key`；`chart_id` 可空（先分析后保存） |

### 1.4 知识、技能与计费

| 表 | 作用 | 关键约束 |
| --- | --- | --- |
| `knowledge_sources` / `knowledge_chunks` | 知识库 | `knowledge_chunks.content` 有 ngram 全文索引 `ft_chunk_content` |
| `skill_versions` | 技能包版本 | 版本化发布，**禁止覆盖旧版本** |
| `usage_ledger` | 额度三态账本 | `grant` / `reserve` / `settle` / `refund`；`idempotency_key` 唯一索引 |
| `orders` / `payment_events` | 订单与支付回调 | 回调幂等 |
| `feedback` | 用户反馈 | — |

## 2. 为什么是单表外壳而不是每域一张表

`chart_records` 用 `domain` 区分术数，`chart_json` 存 `ChartResult` 的完整外壳。

**好处**：
- 新增术数**不需要建表**：本轮新增 11 个域，零张新表（只有 `chart_media` 因图片元信息而独立）；
- 列表、分享、导出、笔记、额度、报告全部自动复用；
- 报告管线的「快照哈希」只对一份 JSON 计算，跨域一致。

**代价**：无法对某个域的字段建索引。当前所有查询都按 `owner_user_id` / `domain` /
`created_at` 走，不需要域内字段索引；真需要时再加生成列。

规范：

- 新增或修改结构**必须新迁移**，禁止改线上表；
- 涉及函数/视图/触发器时显式声明 `search_path` 与权限边界；
- 每张新表评估：索引、默认值、回填策略、旧数据兼容；
- `alembic/versions/` 文件名与 `revision` 沿用 12 位十六进制。

## 4. 归属过滤只有一处

`owner_user_id` 过滤**只在 `app/repositories/` 里做**，由
`tests/test_architecture.py` 守卫。API 层调用 `*_repo.get_owned(...)`，
不在路由里拼 `where` 条件 —— 拼错一处就是越权读。

## 5. 本地起库

```bash
# 项目开发实例：Docker 容器 xuanshu-mysql，对外 127.0.0.1:3307
docker start xuanshu-mysql
docker ps --filter name=xuanshu-mysql

# 首次或容器丢失时重建
docker run -d --name xuanshu-mysql \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=<root 口令> \
  -e MYSQL_DATABASE=xuanshu \
  -e MYSQL_USER=xuanshu_app \
  -e MYSQL_PASSWORD=<app 口令> \
  -v xuanshu-mysql-data:/var/lib/mysql \
  mysql:8.0 --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_0900_ai_ci --ngram_token_size=2
```

`ngram_token_size` **必须为 2**，否则中文全文检索命中率会崩。
系统里 3306 上的 MySQL8 服务是另一个实例，本项目不连它。
