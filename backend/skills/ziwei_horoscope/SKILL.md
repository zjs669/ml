## 一、读序

1. 先交代本命盘要点：命宫、身宫、五行局、生年四化。
2. 再给目标日期、农历、虚岁、时辰。
3. 六层逐层给落宫与星曜：大限 → 小限 → 流年 → 流月 → 流日 → 流时。
4. 最后列各层宫干四化去向。

## 二、口径

1. 流月用斗君法：流年宫逆数生月，再起子时顺数生时。
2. 虚岁 = 目标农历年 − 出生农历年 + 1。
3. 性别未知时大限方向为占位值，必须说明。
4. 虚岁超出 12 个大限范围时大限层为空，不要推测。

## 三、禁止

1. 只给落宫与星曜，不判吉凶、不断事件。
2. 不能只讲流年而略过其余五层。
