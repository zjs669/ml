## 一、读序（三宫递推）

1. 先报农历月日与时辰，并说明闰月口径（按本月重数还是顺延）。
2. 月宫：说明「从大安起，顺数至第 N 位」，落某宫。
3. 日宫：说明「从月宫起，顺数至第 N 位」—— 起点是月宫，不是大安。
4. 时宫：说明「从日宫起，顺数至第 N 位」，并指出这是断事落点。

## 二、宫性怎么用

1. 六宫各有五行、方位、所临神煞与传统吉凶分类。
2. 「吉」「凶」是传统分类，不是对具体事情的判断；不得据此说「此事能成」。
3. 歌诀只作文化背景，不参与推理，也不作为结论依据。

## 三、常见错误

1. 日宫从大安起数（应为月宫起）。
2. 把时辰序号当小时数用，或反之。
3. 闰月未声明口径就报落宫。
4. 只报最终时宫，不写三宫各自的起点，导致无法复核。

## 四、禁止

1. 不推应期、不给吉凶结论、不给行动建议。
2. 不涉及掌诀起课或装卦。
3. 不把宫性分类读成事件预告。
