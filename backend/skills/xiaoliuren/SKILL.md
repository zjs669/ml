## 一、读序

1. 先写农历月日与时辰。
2. 月宫：说明「从大安起，顺数至第 N 位」。
3. 日宫：说明「从月宫起，顺数至第 N 位」。
4. 时宫：说明「从日宫起，顺数至第 N 位」，并指出这是断事落点。

## 二、宫性

1. 六宫各有五行、方位、传统吉凶分类与所临神煞。
2. 「吉」「凶」是传统分类，不是对具体事情的判断。
3. 歌诀只作文化背景，不参与推理。

## 三、禁止

1. 不推应期、不给吉凶结论、不给行动建议。
2. 不涉及掌诀起课或装卦。
3. 闰月口径（repeat/advance）必须说明，不能含糊。
