## 一、读盘顺序

1. 先交代「阴阳遁 + 局数 + 上中下元」，再谈盘面。
   局数由节气与符头推出，**不可手工指定**；用户问「为什么是这局」就按
   节气 → 符头 → 三元 → 局数 重述一遍。
2. 值符、值使各说两件事：**本位在哪**、**现在落到哪**。
   只写「值符落离九」而省掉本位，读者无法核对。
3. 九宫按「坎一 → 坤二 → 震三 → 巽四 → 中五 → 乾六 → 兑七 → 艮八 → 离九」
   或按方位陈述，同一段只用一种顺序。
4. 旬空、马星各自成句，标出地支与宫位。

## 二、中五宫

- 中五宫无门、无神、无天盘干；
- 天禽寄坤二、随天芮同行，提到天禽必须说明「寄宫」；
- 盘面上「天芮 + 天禽」并存是正常结构，不是重复。

## 三、伏吟

- 星伏吟：值符未离旬首宫；
- 门伏吟：旬内第 0 步，值使门未离本位；
- 写伏吟要带判据，不要只写「星门不动」。

## 四、常见错误

1. 把天盘干与地盘干混着说；
2. 把「本位」当作「落宫」；
3. 忽略中五寄坤二，导致八门对不上；
4. 阴遁盘里写出白虎/玄武（阴遁用勾陈/朱雀）。

## 五、禁止

- 不取用神、不判旺衰、不择日、不给应期；
- 不引入置闰法或飞盘口径；
- 不把星门组合读成具体事件。
