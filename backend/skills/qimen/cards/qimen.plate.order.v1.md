1. 先交代「阴阳遁 + 局数 + 上中下元」，再谈盘面。局数由节气与符头推出，不可手工指定。
2. 值符、值使各说两件事：**本位在哪**、**现在落到哪**。
   只写「值符落离九」而省掉本位，读者无法核对，也容易被判成改写盘面。
3. 九宫按「坎一 → 坤二 → 震三 → 巽四 → 中五 → 乾六 → 兑七 → 艮八 → 离九」或按方位（东南西北）陈述，
   同一段里只用一种顺序，不要混着走。
4. 中五宫无门无神，天禽寄坤二随天芮：提到天禽时必须说明它是寄宫，不要当成独立宫位。
5. 星/门若已伏吟，明确写「伏吟」并说明判据（值符归本位 / 值使归本位），不要只写「星门不动」。
6. 旬空、马星各自成句，标出对应的地支与宫位；不要把它们混进某个门或星的描述里。
7. 不取用神、不论旺衰、不择日、不给应期——本版本只出盘面结构。
