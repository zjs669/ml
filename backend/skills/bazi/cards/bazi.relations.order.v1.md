1. 先定位关系发生在哪两柱（年/月/日/时），再谈它是什么关系。
   「日支与月支相冲」和「年支与时支相冲」在叙述上是两件事，不能只说「命局有冲」。
2. 同一组地支可能同时满足多种关系（例如既在三合局内又有相破），
   按「合 → 冲 → 刑 → 害 → 破」的顺序逐条陈述，每条单独引用 rule_id。
3. 只写本次 `triggered_rules` 里真的出现的规则；不要因为「看起来应该有三合」就补写。
4. 不要评价哪一组关系更重要——重要性排序需要旺衰判断，本版本不做。
5. 若两条规则覆盖同一对地支且方向相反，明确写出这是**并列存在**，不要自行取舍。
